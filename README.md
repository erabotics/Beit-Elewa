# بيت عليوه — Beit Elewa

موقع طلب أونلاين لمطعم بيت عليوه: المنيو، السلة، عرض ٣ سندوتشات بـ ١٠٠، توصيل أو استلام من الفرع، والطلب على واتساب + حفظ الطلبات في Google Sheets.

```
index.html   style.css   script.js   img/      ← الموقع (GitHub Pages)
google-apps-script/Code.gs                     ← حفظ الطلبات في Google Sheets
backend/                                       ← (اختياري لبعدين) قاعدة بيانات Supabase
```


تشغيل: افتح index.html في أي متصفح، أو ارفع الفولدر كله على أي استضافة (Netlify / Vercel / GitHub Pages).

الملفات
- index.html   شكل الصفحة
- style.css   الألوان والخطوط والتصميم (الألوان كلها في أول الملف تحت :root)
- script.js       المنيو والسلة والعرض والطلب على واتساب
- img/         صور الأصناف

أشهر التعديلات (كلها في أول script.js)
- رقم الواتساب:        PHONE_WA
- مصاريف التوصيل:      ZONES  (كل منطقة وسعر توصيلها، والاستلام من الفرع دايماً مجاني)
- عنوان الفرع:         BRANCH
- الأصناف والأسعار:   ITEMS  (الاسم، الوصف، السعر، اسم الصورة في فولدر img بدون .jpg)
- العرض:               أي صنف سعره 35 ومش من الإضافات بيدخل في عرض ٣ بـ ١٠٠ تلقائياً

تغيير صورة صنف: حط الصورة الجديدة في img/ (jpg، يفضل مربعة أو 4:3، حوالي 600 بكسل)
وغير قيمة img للصنف ده في ITEMS.

حفظ الطلبات في Google Sheets
----------------------------
كل طلب بيتسجل لوحده في شيت خاص بالمدير (التاريخ، رقم الطلب، الأصناف، الإجمالي، بيانات العميل)،
وفي نفس اللحظة العميل بيروح للواتساب زي ما هو.
- الكود في: google-apps-script/Code.gs (خطوات التركيب مكتوبة بالعربي في أول الملف)
- بعد التركيب حط رابط الـ Web App في script.js مكان: PASTE_YOUR_WEB_APP_URL_HERE
- رقم الطلب (زي BE-1008-2130-K7QX) بيظهر في رسالة الواتساب وفي الشيت، عشان تطابقهم.
- عمود "الحالة" في الشيت فيه قائمة: جديد / اتأكد / بيتجهز / خرج للتوصيل / جاهز للاستلام / اتسلم / ملغي
- لو غيرت سعر أو مصاريف توصيل: غيرها في script.js وفي Code.gs الاتنين.

رفع الموقع على GitHub Pages (مجاناً)
-----------------------------------
1. ادخل github.com بحسابك ← New repository ← الاسم مثلاً: beit-elewa ← Public ← Create repository
2. في صفحة الـ repository: Add file ← Upload files ← اسحب كل محتويات الفولدر ده
   (index.html و style.css و script.js و فولدر img) ← Commit changes
   (فولدر google-apps-script مش لازم يترفع، ده بيتحط في جوجل شيت)
3. Settings ← Pages ← Source: Deploy from a branch ← Branch: main و /(root) ← Save
4. استنى دقيقة أو اتنين، الموقع هيبقى على: https://اسم-حسابك.github.io/beit-elewa/
5. الدومين بتاعك (بعد ما تشتريه): Settings ← Pages ← Custom domain ← اكتب الدومين ← Save
   وفي لوحة تحكم الدومين ضيف سجلات DNS اللي GitHub بيقولك عليها، وبعدها فعّل Enforce HTTPS.
6. أي تعديل بعد كده: افتح الملف على GitHub ← القلم ← عدّل ← Commit، والموقع بيتحدث لوحده في دقيقة.

ملاحظة: الـ repository العام بيبقى الكود فيه ظاهر لأي حد (ده طبيعي لأي موقع). رابط الشيت اللي في
script.js بيسمح بس بإضافة طلبات، محدش يقدر يقرأ الشيت أو يعدله غير حساب المدير.
